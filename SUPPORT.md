# Editor support

JSON API Forge Editor is provided without a support warranty.

For a reproducible bug, include Editor version, operating system and
architecture, Qt version/build artifact, server v0.5.2 status, sanitized steps
and the relevant non-secret log excerpt. Never publish passwords, founder
setup tokens, invitation tokens, bearer sessions, call tickets, API keys,
private project files or database data.

Use the canonical repository's private vulnerability reporting route for
security issues. Questions about redistribution, OEM use or alternative
licensing require separate written authorization from the Project Owner.
