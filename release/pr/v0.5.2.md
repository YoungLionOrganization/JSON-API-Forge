## Summary

Prepare the canonical `main` server for v0.5.2. Shared resource caches could expose fields from a less restrictive endpoint, heterogeneous batches could drop submitted fields, and request timeout could return 504 while the endpoint kept running. This patch isolates cache policies, preserves transactional batch data and cancels the actual async endpoint before reusing its admission slot.

- Fix ISO datetime handling, nullable cursors, PUT defaults, PostgreSQL BIGINT declarations, non-finite parameters and media cleanup/token handling.
- Bound DNS/JWKS/readiness waits, reuse app-scoped JWKS clients, isolate DNS from file/hook executor work, lazily create HTTP-source clients and avoid repeated schema checks. Optional `total_timeout_seconds` preserves legacy configuration when unset.
- Add a manual validate/draft/publish server workflow with exact-SHA CI/CodeQL/platform gates, artifact provenance, archive/checksum checks, resumable draft uploads and remote digest verification.
- Update README, release notes/procedure/checklist and schemas, with reproducible latency probes and documented compatibility/cancellation limits.

Editor, Python SDK and example branches remain separate. No automatic physical database migration, deployed Passenger bridge replacement, merge or public release is performed by this PR.
