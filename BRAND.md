# Brand and Naming Policy

The canonical project mark is `assets/branding/JSON-API-FORGE_logo.png`. Keep its aspect ratio, clear space and dark-background treatment intact. The Qt editor uses this exact asset as its application/window icon and about-screen mark.

The source-code license does not grant trademark or branding rights.

You may truthfully say that your service **uses JSON API Forge** or is **compatible with JSON API Forge**. You may not name an unofficial fork, product or distribution "JSON API Forge" in a way that implies it is an official project release, and you may not use project logos or branding to imply sponsorship or endorsement without permission.

This policy does not claim that any mark is registered. It states the permissions provided with this repository.
