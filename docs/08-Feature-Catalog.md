# Feature Catalog

Forge v0.4.x includes: multi-project JSON fragments; SQL CRUD; transactional SQL/RPC; Mongo resources; file/static/HTTP data sources; custom FastAPI endpoints; API keys; local/JWKS JWT; row ownership and tenant isolation; memory/Redis cache and rate limiting; SSE/WebSockets; local media; audit; health/readiness/metrics; OpenAPI/project docs; CLI/schema/doctor/migration tooling; Python/TypeScript client references; Docker and Passenger entry points.

The catalog describes implemented primitives, not promised future adapters. Check `KNOWN_LIMITATIONS.md` for important boundaries.
