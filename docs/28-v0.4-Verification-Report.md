# v0.4 Verification Report

The initial v0.4.0 GitHub-hosted runs exposed two independent defects: an obsolete `app/config` directory was discovered as a third project and blocked strict validation/tests, and completed idempotent HTTP replays did not surface the documented replay marker. The same run demonstrated that the transaction/unique constraint itself prevented duplicate side effects.

The review also surfaced FastAPI `ORJSONResponse` deprecation warnings, dependency-floor/security maintenance needs, and a release manifest that did not describe every tracked legacy file.

v0.4.1 addresses those findings, additionally suppresses background hooks on replay, removes root legacy hooks, updates version defaults/generated schemas, fixes the Mongo tenant example and adds manifest completeness as CI policy.

A release is not considered canonical-host verified until the final uploaded/committed v0.4.1 tree passes the GitHub workflows.
