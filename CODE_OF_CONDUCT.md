# Code of Conduct

JSON API Forge aims to keep technical discussion rigorous, useful and respectful.

## Expected behavior
- Discuss code, architecture and security claims on their technical merits.
- Give reproducible bug reports and concrete review feedback where possible.
- Respect privacy, credentials, unpublished vulnerabilities and confidential information.
- Disagree without harassment, threats, personal attacks or discriminatory abuse.
- Keep issues and pull requests relevant to the project.

## Unacceptable behavior
Harassment, doxxing, threats, deliberate disruption, spam, malicious payloads, credential publication, or knowingly exposing an unpatched vulnerability in a way that unnecessarily endangers deployments may result in moderation or removal from project spaces.

## Enforcement
The Project Owner and delegated maintainers may edit, hide, lock or remove project interactions and may restrict participation when reasonably necessary to protect contributors, users or the project.

For security vulnerabilities, follow `SECURITY.md` instead of posting exploit details publicly.
